Privacy Policy: Battle Alert Bot

This Privacy Policy explains how Battle Alert Bot ("the Bot") collects, uses, and protects information when you interact with its services.

1. Information We Collect

  • Server IDs, channel IDs, and role IDs required for bot functionality
  • User IDs related to command usage and alert targeting
  • Configuration data set by server administrators

2. How Information Is Used

  • To operate and provide alerting features
  • To deliver messages and notifications as configured
  • To improve performance and reliability of the Bot

3. Data Storage

Data is stored only as long as necessary to provide the Bot’s functionality. No unnecessary or excessive data is retained.

4. Data Sharing

Battle Alert Bot does not sell, trade, or share user data with third parties, except where required by law or to comply with platform requirements.

5. User Responsibilities

Users and server administrators are responsible for ensuring that no sensitive or personal information is transmitted through the Bot.

6. Security

Reasonable measures are taken to protect stored data; however, no system can be guaranteed to be completely secure.

7. Changes to This Policy

This Privacy Policy may be updated at any time. Continued use of the Bot constitutes acceptance of any changes.

8. Contact

For questions or concerns regarding this policy, please contact the developer or support team associated with Battle Alert Bot.
